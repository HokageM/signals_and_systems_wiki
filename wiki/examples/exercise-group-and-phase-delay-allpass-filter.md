# Exercise — Group and phase delay of an allpass filter

Source: [Lecture 3, pp. 6–7](../../raw/signals_3.pdf). Builds on
[Phase and group delay](../concepts/phase-and-group-delay.md).

## Setup

An analog filter has frequency response

$$H(f) = \frac{1-j2\pi f T}{1+j2\pi f T}$$

## a) Magnitude and phase response

$$|H(f)| = \frac{|1-j2\pi f T|}{|1+j2\pi f T|} = \frac{\sqrt{1^2+(2\pi f T)^2}}{\sqrt{1^2+(2\pi f T)^2}} = 1$$

so $H(f)$ is an **allpass filter** (p. 6).

$$\varphi(f) = \varphi_Z(f) - \varphi_N(f) = \arctan\!\left(\frac{-2\pi f T}{1}\right) - \arctan\!\left(\frac{2\pi f T}{1}\right) = -2\arctan(2\pi f T)$$

(p. 6).

![Allpass filter magnitude and phase response](../assets/plots/allpass_filter_magnitude_phase.png)

*Figure: $|H(f)|=1$ for all $f$; $\varphi(f)$ decreases monotonically from
$\pi$ to $-\pi$. Generated by [`lecture3_plots.py`](../assets/plots/lecture3_plots.py).*

## b) Classification

This is an **allpass filter**: constant magnitude response, frequency-
dependent phase only (p. 6). See
[LTI systems in the s-domain](../concepts/lti-systems-s-domain.md) for the
general allpass pole/zero condition.

## c) Phase delay and group delay

$$t_p(f) = \frac{-\varphi(f)}{2\pi f} = \frac{2\arctan(2\pi f T)}{2\pi f} = \frac{\arctan(2\pi f T)}{\pi f}$$

$$t_g(f) = \frac{-1}{2\pi}\frac{d}{df}\varphi(f) = \frac{1}{2\pi}\cdot\frac{2\cdot 2\pi T}{1+4\pi^2 f^2 T^2} = \frac{2T}{1+4\pi^2 f^2 T^2}$$

using $\dfrac{d}{dx}\arctan(x) = \dfrac{1}{1+x^2}$ (p. 7).
