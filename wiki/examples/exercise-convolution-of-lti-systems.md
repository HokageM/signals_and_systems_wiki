# Exercise — Convolution of LTI systems

Source: [Lecture 2, pp. 4–8](../../raw/signals_2.pdf). Builds on
[LTI systems](../concepts/lti-systems.md) and [Convolution](../concepts/convolution.md).

## Part 1 — exponential input through an integrator

An LTI system has impulse response $h(t) = \varepsilon(t)$ (unit step) and
input $x(t) = e^{-\alpha t}\varepsilon(t)$, $\alpha > 0$ (p. 4).

**a)** Sketch $h(t)$ and $x(t)$: $h(t)$ is a unit step; $x(t)$ starts at
height 1 at $t=0$ and decays to the step-like plateau $1/\alpha$ under
integration (p. 4).

**b)** Is the system causal? **Yes**, because $h(t) = 0$ for $t < 0$ (p. 4).

**c)** Compute $y(t) = h(t)*x(t) = \int_{-\infty}^{\infty} x(\tau)\,h(t-\tau)\,d\tau$:

- For $t < 0$: no overlap between the shifted/reflected $h$ and $x$, so
  $y(t) = 0$.
- For $t \ge 0$:
  $$y(t) = \int_0^t e^{-\alpha\tau}\,d\tau = \left[-\frac{1}{\alpha}e^{-\alpha\tau}\right]_0^t = \frac{1}{\alpha} - \frac{1}{\alpha}e^{-\alpha t}$$

$$y(t) = \begin{cases} 0, & t<0 \\ \dfrac{1}{\alpha}\big(1-e^{-\alpha t}\big), & t \ge 0 \end{cases}$$

(p. 5). This matches [Convolution with the unit step](../concepts/convolution.md):
convolving $x(t)$ with $\varepsilon(t)$ integrates $x(t)$.

## Part 2 — raised-cosine impulse response, rectangular input

A second LTI system has impulse response

$$h(t) = \begin{cases} \tfrac12\Big(1+\cos\big(\tfrac{\pi t}{T}\big)\Big), & 0 \le t \le T \\ 0, & \text{else} \end{cases}$$

and input $x(t) = \mathrm{rect}(t/T)$ (height 1, support $[-T/2, T/2]$) (p. 6).

**a)** Sketch $h(t)$: a single raised-cosine "hump" on $[0,T]$, zero elsewhere
(p. 6).

**b)** Is the system causal? **Yes**, because $h(t) = 0$ for $t < 0$ (p. 6).

**c)** Compute $y(t) = x(t)*h(t) = \int_{-\infty}^{\infty} x(\tau)\,h(t-\tau)\,d\tau$
piecewise, since both $x$ and $h$ have finite support (total overlap width
$2T$) (pp. 7–8):

- $t < -T/2$: $y(t) = 0$ (no overlap).
- $-T/2 \le t \le T/2$:
  $$y(t) = -\frac14\Big(t+T+\frac{T}{\pi}\sin\big(\tfrac{\pi t}{T}\big)\Big)$$
  (intermediate form derived from integrating the raised-cosine kernel, p. 7).
- $T/2 \le t \le 3T/2$: a second piecewise branch evaluated with the
  overlapping limits shifted by $T$, with intermediate algebra on p. 8
  (the original derivation is lengthy; the structure mirrors the first
  branch with sign/shift adjustments — see source for the full steps).
- $t > 3T/2$: $y(t) = 0$.

The notes flag this third branch's derivation as algebraically intensive;
treat the final closed form on p. 8 as the authoritative result if a precise
formula is needed, and recompute from the integral definition in
[Convolution](../concepts/convolution.md) if verifying by hand.
